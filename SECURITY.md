# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's **Security** tab and select **Report a vulnerability** to submit a
private report through GitHub Private Vulnerability Reporting.

Include the affected version, reproduction steps, potential impact, and any
suggested mitigation. You should receive an initial response within seven days.

Never include live API keys, access tokens, customer data, or other secrets in
a report. Revoke any credential that may already have been exposed.
